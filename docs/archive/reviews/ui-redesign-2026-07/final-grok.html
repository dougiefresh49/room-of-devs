Room of Devs · final synthesis · locked candidate

Floor & Table One floor for voices. One table for objects. One tape for memory. The same room at three distances.

Thesis. Stop building a chat app that happens to speak. Build a room: whoever holds the floor is heard; whatever is being talked about sits on the table; everything that happened lands on one scrubbable tape. Screen glances, sketches, files, and huddles stop being four features — they are things you put on the table while someone holds the floor. Light answers direction of sound: white light lands on a dark seat when an agent is on air; the seat itself becomes light when your mic opens (talkback). Persona color is a jersey, never a state.

00

The model

Three objects. Every surface is just a different distance from them.

Object one

The Floor

Ears are single-lane. Exactly one voice speaks. Queued agents wait with a one-line preview. Group calls are the same floor passed between more people — not parallel monologues.

Object two

The Table

One shared surface holds the thing being discussed: a consentful screen glance, a napkin sketch, a pasted stack trace, a file. Agents draw; you draw back. Attachments need no second home.

Object three

The Tape

Every spoken line, sketch, glance, decision, and typed reply is a moment on one timeline. Replay, catch-up, and “replay Donnie’s last” are all seeks. Per-agent history is a filter, never a separate app.

Distance 1 · overheard
The Strip
~380×150 float over other apps. Never steals focus. No text inputs. Who’s talking / who’s waiting / talk bar.
Distance 2 · seated
The Den
Main Mac window. Seats by urgency, table in the middle, tape along the bottom, typed reply + attach always ready.
Distance 3 · pocketed
The Earpiece
Phone is a walkie, not a tiny Mac. Opens call-shaped. Thumb zone owns talk, type, catch-up, decisions.

Provenance. Floor + places-to-stand ← round1-C Soundstage. Table-as-object ← round2-B (kept whole — best answer for glance/draw/attach). One tape + three distances ← round2-C / round1-B LAIR FM. ON AIR / TALKBACK light axis ← synth-C. Density seats ← synth-A/B ladder. Phone-as-walkie ← unanimous round1.

07

Rationale

Opinionated calls. A genuine better idea beat a faithful merge — but every major adoption or rejection is named.

kept · structural
Table over timeline
round2-B’s table is the only prior idea that makes glance, draw, attach, and huddle the same verb. Channel-strip desks (synth-A) are better instruments for pure voice — and worse homes for objects. The Den is both: seats for attention, table for stuff.
kept · collision-proof
ON AIR is light; talkback inverts
Rejected lime/green/amber “speaking” hues from round1/round2 — they eventually sit next to a jersey. synth-C’s axis (emit vs receive) is the cleanest fix for white-on-white PTT collision.
kept · honest
One floor, visible baton
Equal grids pretend six agents speak at once. Floor + queue (round1-C, round2-B) makes the product honest. Huddle is floor-sharing, not four threads on a conference line.
kept · memory
One tape
round1-B / round2-C. Catch-up, replay, sketches, and glances are seeks. Per-agent panes are filters. Interpreter plans address the tape by identity + “last.”
rejected
Phone as tiny Mac
Every round1 board that treated the phone as a walkie felt truer. Couch use is listen / decide / talk / type — not rearrange a studio console.
new · brief
Type beside talk, always
Headphones on, type the question, hear the reply — or silent room. Composer + attach on Den and Earpiece; Strip stays non-activating (drop-file only).

Cut vs add

cut
Per-agent chat as home
Threads exist as tape filters. The home is the room. This kills tab hell and matches how the developer actually listens.
cut
Ambient always-on screen share
Glance is explicit, timed, and logged on the tape. Consent is the product, not a settings footnote.
add
Table shelf
One object on the table at a time; prior glances/napkins/files sit on a shelf. Prevents collage chaos without losing history.
add
Huddle auto-adjourn
From round2-B: huddles are expensive. Auto-adjourn after ~2m of your silence; floor beam can show a faint spend tick.
