Concept · Broadcast Den

The Room is a control booth, not a dashboard.

Agents are on-air talent. Hierarchy is driven by signal state — who's speaking, who's waiting, who needs a decision — not by card chrome or persona flair. Persona accents stay on the avatar ring; semantic lights (amber on-air, teal working, coral hand-raised) own the glanceable read across a wall of cards. Playful voice, instrument precision.

Geometry

  • Radius ladder: 4 → 7 → 11 → 16. Cards at 11; sheets/dock at 14–16.
  • 8px base rhythm. Dense cards, loose board chrome.
  • No soft purple wash. Amber is the only “live” glow.

State vs accent rule

  • Persona color fills the avatar disc — never the card border.
  • State owns border + badge + optional glow. Speaking wins every conflict.
  • PTT is white (neutral mic) so it never collides with Raph/Leo red/blue.

03 · Rationale

Opinionated calls. What maps to shadcn. What I'd cut or add.

Key decisions

  • Broadcast lights over character chrome. Speaking is amber ON AIR everywhere — dock rim, card border, badge, summary accent. Persona color never owns the border; it stays on the avatar fill so six turtles don't become a rainbow traffic jam.
  • PTT is white, not accented. A held grant is a mic event, not a persona event. White ring + waveform reads as “you are live to this agent” without colliding with Raph red or Leo blue.
  • Quiet dock still earns its pixels. Collapsed state shows who needs you (hand / ask counts), not a dead logo. Glanceable while coding.
  • Interpreter plans are messages. Voice commands render as ChainOfThought steps with outcomes in the thread — durable, replayable, auditable. Not a disappearing toast.
  • Confirm is a spoken sentence. Spawn UX ends on “Start Donnie · sonnet · jellyfin-streamline” — the same cadence the product speaks in.

Cut / keep / add

Keep

Per-agent transport (pause/stop/replay/0.8×), hold-to-grant, live badge, hand preview, device toggle, catch-up.

Cut

Per-card “status info” as a permanent button — fold into a long-press / ··· menu. Grid is too precious for tertiary chrome.

Cut

Swap-persona on the card face. Move to card menu; accidental swaps mid-call are worse than one extra tap.

Add

Quiet-dock “needs you” strip (hands + asks). Interpreter plan as a thread object. Confirm-as-sentence on picker.

Add

Line-level karaoke only (not word). Sync cost stays low; readability stays high on a 390-wide screen.
