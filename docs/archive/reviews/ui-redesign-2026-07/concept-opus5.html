Room of Devs · redesign concept · dark-first

The Booth Your agents aren't cards in a dashboard. They're channels on a live board — and exactly one of them is on air.

Thesis. Every screen in this product answers one question first: who is talking right now, and what did they just say? So the room is built like a broadcast console — horizontal channel strips instead of a grid of equal tiles, a tally system where state is a lamp plus a word (never color alone), and a single ON AIR treatment that wins by light, not by hue, so it can never collide with Raph's red or Donnie's purple. Personas own identity — ring, edge bar, voice — and nothing else; semantics own everything that has to be read across a wall at a glance. And the mic is a talkback bar: the same hold-to-talk affordance on every surface, always the widest target on the card.

System sans for anything a human wrote or an agent said. ui-monospace for anything the machine knows: state, timers, model, path, counts. That split alone tells you what's speech and what's telemetry.

Spacing & radius

4px base. Strip padding 11/12, gaps of 8 between strips, 14/16 for pane padding, 22 for phone sheet breathing room. Nothing is centered that could be left-aligned.

Radius is equipment-grade: 5px on controls, 8px on strips, 12px on panes, 20px only where iOS demands it (sheets), 999px reserved for two things — lamps and the round talkback key. Rounder = more physical = touch it.

Motion budget: lamps breathe (1.7s), the on-air meter animates, nothing else moves. The avatar's 70ms frame swap is the only fast thing on screen and it must never compete.

The avatar contract

Every avatar is a bare square <img> in a round mask with a 2px persona ring drawn by the parent. No React state, no CSS transitions, no filters on the image itself — the ring, glow, and lamp all live on sibling elements so the 70ms frame swap stays a single img.src write outside the render tree.

Sizes: 44 panel strip, 40 phone strip, 52 dock, 132 call screen. Placeholders below are initials-in-a-disc.

07 Rationale

Why this instead of a nicer grid

Strips, not tiles

A tile grid forces every agent into the same rectangle, which means the speaking agent — the only one with content worth reading — gets the same 180px as the one that's been idle for an hour. Strips are full width, so the on-air channel can grow a caption line, a preview, and a talkback bar without reflowing the wall.

It also matches how the room actually behaves: a list has a top, and the top is “who's up.” Sort order is state-driven (on air → asking → hand up → working → idle → stale), so the thing you need is always the first strip.

ON AIR is light, not hue

With four saturated persona accents in play, any hue chosen for “speaking” eventually collides with a persona. So the most important state in the system is achromatic: brighter surface, white lamp, white ring, white transport. It reads across the room and it works identically for Raph and Donnie.

The rest of the tally set is chosen to be far from the persona palette: cyan (working) and amber (hand up) belong to no character, and asking gets hot pink — loud, unmistakable, and never an accent.

Every state is a lamp and a word

Semantic color is never load-bearing alone. Each state renders as a lamp plus a mono uppercase label, so state survives colorblindness, a dimmed display, and the 26px dock sliver. It also means new states can be added without hunting for an unused hue.

One talkback affordance, four surfaces

The mic is always the widest target on its container: a full-width bar on the desktop strip, a full-width bar in the dock, a 62–88px round key on the phone. Hold to open, release to send, drag-off to cancel — one muscle memory. Grant state is expressed the same way everywhere (white ring + “release to send”) so you never have to check whether you're actually hot.

The dock's bar is a bar, not a button, because a non-activating panel gets no focus ring and no hover cursor to lean on — the target has to be big enough to hit blind.

The words are the product

Three surfaces render the same spoken text at three densities: one clipped line in the dock, a scrolling markdown block in the program pane, a 16px karaoke transcript on the phone. All three share the word-timing stream, so the highlight is consistent — and when audio is off, the highlight still tells you where you'd be.

Markdown renders with real hierarchy (h4, bullets, inline code) because agents write like devs. A summary that flattens code spans to plain text is a worse summary.

Cost is visible, quietly

“from cache, no spend” on an interpreter replay, “superseded ×1” on a stale queue item, ghost bubbles for live narration that never bills a rerun. This app charges per sentence; a UI that hides that trains bad habits. It's one mono line, never a warning banner.

What I'd cut

  • The separate transport bar. Transport belongs to a channel, not to the room. It lives on the on-air strip, in the dock, and in the player — three places you're already looking.
  • “Replay slower” as a peer button. On the phone it's one press of the speed ToggleGroup. It only stays as its own control on desktop and dock, where there's no speed UI.
  • Grid density options / card size settings. Strips are one size. The wall's information density is set by state sort order, not by a preference.
  • The room-level “current mode” label. Mode is implied by what's lit: hazard stripes = held, cyan pill = live. A word that says “normal” earns nothing.
  • Hide-agent as a top-level phone action. Demoted into the overflow menu — hiding a dev is rare, and it currently costs a thumb-reachable slot that chat deserves.

What I'd add

  • Cue count as a first-class room object. One number in the bar, one “catch up” action on the phone: play everything unheard in order, oldest first, at 1.25×.
  • Interpreter history. Every plan is kept — the second panel in surface 5. It's the only way to trust a voice command layer: you can see what it did, and undo it.
  • Destructive-step gating in plans. Kill/spawn stop the plan and ask inline rather than executing and apologising.
  • “Superseded” shown on the strip, not buried. If an agent spoke three times and you only get the last, the wall should say so — that's a genuine trust issue with a queue.
  • Spend breadcrumbs (“from cache, no spend”) anywhere a replay could have cost money.
  • Sorted-by-state wall with a frozen top slot so the on-air strip never jumps out from under your cursor mid-click.
