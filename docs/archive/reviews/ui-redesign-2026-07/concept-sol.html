07 / RATIONALE

Character, under control.

The system celebrates the cast through voice, avatar, and accent—not themed chrome. That restraint makes moments of speech and live control feel special.

Identity ≠ urgency

A persona’s accent stays on the avatar and selected controls. A dedicated semantic rail handles working, speaking, asking, stale, and hand-raised states.

Speech earns the light

Only the active speaker gets a luminous surface, animated level meter, and the summary pane. The room has one visual lead at a time.

PTT is a physical gesture

Press-and-hold changes label, color, and glow immediately. Release ends the grant. On phone it stays beside the composer; in the dock it never opens input.

Plain image, rich frame

Every avatar is a plain <img>, ready for out-of-React 70 ms mouth-frame swaps. State decoration lives in sibling layers and never disrupts lip-sync.

Surface / need
shadcn + AI Elements composition
Room + agent cards
Card, Avatar, Badge, Button, Tooltip, DropdownMenu; ScrollArea for the room and summary. Domain custom: signal rail, lip-sync frame, hold PTT.
Transport + routing
ToggleGroup, Slider, Button, Popover for playback speed and device routing; Toast / sonner for held-room and handoff confirmation.
Phone player
Sheet, Slider, Button. Domain custom: waveform and karaoke line progress, fed by the audio clock outside React.
Agent thread
AI Elements Conversation, Message, PromptInput; shadcn Button and Avatar. Replay is message-local, not buried in a menu.
Interpreter plan
AI Elements Task, ChainOfThought, Reasoning, adapted to show only user-visible commands and outcomes—never private model reasoning.
Picker + safety
Dialog on desktop, Sheet on phone; Tabs, Select, Checkbox, Avatar, Button, AlertDialog for explicit launch and kill confirmation.

Cut from primary view

Kill, swap persona, superseded history, and slower replay live in menus or long-press detail. They remain available without taxing every glance.

Add to the system

A single playback-lease indicator clarifies which device owns audio. “Room remains held” persists after interpreter commands so automation never hides durable state.
