# RIG gallery (dev-only)

Local playground for every `@room/ui` RIG primitive in every state.

```bash
pnpm --filter @room/ui dev          # vite gallery
pnpm --filter @room/ui gallery:build
```

Never shipped — not referenced by panel or mobile builds.

**Superseded:** the live component catalog is the prototype tool crib at [`/crib`](http://localhost:5180/crib) (port 5180) — generated from `prototype/src/crib/crib-manifest.ts`. This gallery remains as a dev fallback until deletion.
